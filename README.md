# GTQ 포토샵, 가볍게 시작하기

이 폴더는 "AI 시대에 GTQ를 따야 하는 이유와 학습법" 수업에서 쓰는 연습 자료 모음입니다.
강의를 들으면서 편하게 훑어보세요. 다 외울 필요는 없습니다. 손으로 한 번씩 따라 해 보는 것이 가장 빠른 공부입니다.

---

## 1. 왜 지금 GTQ일까?
* [GTQ(그래픽기술자격) 공식 사이트 바로가기](https://license.kpc.or.kr/nasec/qlfint/qlfint/selectGtqinfomg.do)
* [연습+시험자료 다운로드](https://drive.google.com/file/d/1b496_7K5k4FDznU7wgFHifLlqqz4xUT3/view?usp=sharing)
* [포토샵 기초 연습자료 다운로드](https://drive.google.com/file/d/18IOQ87XGr8h5S-p2lV67PwTlh7k17UoE/view?usp=drive_link)

요즘은 AI가 그림을 뚝딱 만들어 줍니다. 그런데 막상 써 보면 손가락이 이상하거나, 글자가 깨지거나, 배경이 어색한 경우가 많습니다.
결국 마지막 손질은 사람이 포토샵으로 합니다. 그래서 포토샵 기본기는 AI 시대에도 여전히 필요합니다.

- GTQ 1급과 2급은 국가공인 자격입니다(공인민간자격).
- 국내 디자인 자격 중 응시자가 가장 많은 시험입니다.
- AI 디자인 자격인 GTQ-AI에도 포토샵으로 편집하고 합성하는 문제가 들어 있습니다. GTQ에서 배운 실력이 그대로 이어집니다.

## 2. GTQ 1급 시험, 한 장으로 보기

| 항목 | 내용 |
|---|---|
| 시험 방식 | 포토샵 실기 100% (이론 시험 없음) |
| 시험 시간 | 90분, 4문제 |
| 합격 기준 | 100점 만점에 70점 이상 (2급은 60점 이상) |

| 문제 | 이름 | 배점 | 핵심 기능 |
|---|---|---|---|
| 1번 | 고급 Tool 활용 | 20점 | 펜 도구, 패스 저장, 클리핑 마스크, 필터, 모양 도구 |
| 2번 | 사진편집 응용 | 20점 | 색상 보정, 필터, 레이어 스타일 |
| 3번 | 포스터 제작 | 25점 | 레이어 마스크, 혼합 모드, 문자 효과 |
| 4번 | 웹 페이지 제작 | 35점 | 패턴, 펜 도구, 앞 문제 기능 종합 |

4번이 35점으로 가장 큽니다. 그런데 4번은 1~3번 기능을 모두 섞은 문제라서, 앞 문제를 잘 익히면 4번도 자연스럽게 풀립니다.

## 3. 이 폴더에 있는 연습 자료

수업 순서대로 하나씩 열어 보세요.

### path_따라그리기 (펜 도구)

GTQ 1급 1번 문제의 "패스 저장"을 연습하는 그림 10장입니다.

- 01 깃발(직선만)부터 06 천체망원경(앵커 28개)까지 점점 어려워집니다. 07~10은 추가 연습입니다.
- 그림 속 번호 순서대로 클릭하면 됩니다. 주황색 방향선이 있는 곳에서만 드래그하세요.
- 다 그렸으면 Paths(패스) 패널에서 이름을 붙여 저장하는 것까지가 한 세트입니다.

### pattern_따라그리기 (패턴)

GTQ 1급 4번 문제의 "패턴(달 모양, 해와 별 모양)"을 연습하는 자료 10세트입니다.

- `1_마스크전`: 50 x 50 px 타일에 모양 두 개를 엇갈리게 놓고 패턴으로 등록하는 단계입니다.
- `2_마스크후`: 그 패턴을 펜으로 그린 모양 안에만 보이게 만든 결과입니다.

### 누끼따기_연습 (배경 지우기)

실제 사진 10장에서 물체만 남기고 배경을 지우는 연습입니다.

- `_전.jpg`가 원본, `_후.png`가 정답입니다. 내가 만든 결과를 정답과 겹쳐 보며 빠진 곳을 찾아보세요.
- 쉬운 것(달, 귤, 골프공)부터 어려운 것(화분, 단풍잎, 알람시계) 순서로 되어 있습니다.

### 마스크_연습 (클리핑 마스크, 레이어 마스크)

실제 사진 10장으로 두 가지 마스크를 연습합니다.

- 01~05: 모양 안에 사진 넣기 (1번 문제 방식)
- 06~10: 사진 한쪽을 가로, 세로, 대각선으로 흐릿하게 하기 (3번, 4번 문제 방식)

각 폴더에 들어 있는 안내 문서(md 파일)에 도구 이름과 작업 순서가 자세히 적혀 있습니다.

## 4. 꼭 기억할 단축키 10개

| 단축키 | 기능 |
|---|---|
| Ctrl + N | 새 문서 만들기 |
| Ctrl + Z | 실행 취소 (여러 번 누르면 계속 뒤로) |
| Ctrl + T | 자유 변형 (크기, 회전) |
| Ctrl + J | 레이어 복제 |
| Ctrl + D | 선택 해제 |
| Ctrl + I | 반전 (마스크에서 보이는 쪽과 가리는 쪽 바꾸기) |
| Ctrl + Alt + G | 클리핑 마스크 만들기 |
| Ctrl + + / Ctrl + - | 화면 확대, 축소 |
| Space (누른 채 드래그) | 화면 이동 |
| P | 펜 도구 |

## 5. 처음 하는 사람이 자주 하는 실수

- 파일 이름을 틀리게 저장한다. 시험에서는 "수험번호-성명-문제번호"를 정확히 지켜야 합니다. 틀리면 미제출로 처리됩니다.
- jpg만 저장하고 psd를 빼먹는다. 두 가지 형식을 모두 저장해야 합니다.
- psd를 원래 크기 그대로 저장한다. psd는 1/10 크기(예: 40 x 50 px)로 줄여서 저장합니다.
- 패스를 그려 놓고 Paths(패스) 패널에 저장하지 않는다. 저장 안 하면 감점입니다.
- 레이어를 합쳐 버린다. 기능마다 레이어를 나눠 두어야 점수를 받습니다.

시험 세부 규칙은 회차마다 문제지에 적혀 있으니, 시험 당일 문제지를 가장 먼저 꼼꼼히 읽으세요.

## 6. 혼자 공부할 때 추천 순서

1. 기능 하나씩 익히기 (펜 도구, 마스크, 패턴, 색상 보정)
2. 문제 하나씩 따라 하기 (1번부터 4번까지)
3. 기출문제를 시간 재지 않고 끝까지 풀어 보기
4. 기출문제를 90분 타이머를 켜고 풀어 보기
5. 내 결과물과 문제지의 출력 형태를 나란히 놓고 다른 곳 찾기

## 7. AI는 이렇게 쓰면 좋아요

- "포토샵에서 클리핑 마스크는 어떻게 만들어?"처럼 기능을 물어보기
- 막혔을 때 내 화면 상황을 설명하고 원인을 물어보기
- 연습용 소재 이미지를 AI로 만들어 반복 연습하기

단, GTQ 시험장에서는 AI를 쓸 수 없습니다. 결국 내 손이 기억하고 있어야 합니다.
